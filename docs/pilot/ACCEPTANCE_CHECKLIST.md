# Pilot report acceptance checklist

- [ ] Customer authority and repository scope are recorded.
- [ ] Read-only access and agreed time window are recorded.
- [ ] Evidence export origin and collection time are stated.
- [ ] Run counts reconcile to the evidence included in scope.
- [ ] Each finding links to supporting run/job/log evidence or is marked UNKNOWN.
- [ ] Claims distinguish observed facts, estimates, and recommendations.
- [ ] Secrets and unrelated customer data are absent from report and logs.
- [ ] Deterministic validation passed; evaluation record is linked.
- [ ] Known omissions and sampling limits are present.
- [ ] Human reviewer approved the exact report digest and delivery resource.
- [ ] Customer-approved delivery channel and payment status are recorded separately.
- [ ] Retention/deletion date is recorded.
