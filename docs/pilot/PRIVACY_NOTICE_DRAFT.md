# Privacy notice draft for pilot review

Planning draft only, not a published notice or legal advice. Before customer use, specify operating entity, contact, jurisdictions, lawful basis, subprocessors, retention schedule, and applicable rights after qualified review.

For an authorized CI reliability review, the operator may process repository identifiers, workflow/run/job metadata, relevant log excerpts, coordination contact details, and report evidence. Do not submit secrets, unrelated personal data, or source code unless separately agreed and necessary. Access should be read-only and limited to the named repository and period.

Data is used to prepare and review the requested report. The local MVP stores submitted task payloads and evidence in its database; it has no customer-facing deletion workflow, encryption-at-rest configuration, hosted processing, or external LLM provider. Protect the local database and delete customer data under an agreed retention plan. Report delivery and subprocessors require explicit approval.
