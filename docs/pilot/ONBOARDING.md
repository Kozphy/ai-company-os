# Pilot onboarding instructions

1. Confirm fit for a read-only review of one repository.
2. Agree scope, time window, price hypothesis, delivery timing and retention before accepting work.
3. Obtain written authorization with `CUSTOMER_AUTHORIZATION.md` and confirm authority.
4. Select least-privilege read-only access or a customer-generated export. Never request personal access tokens in chat or email.
5. Validate the export schema and remove secrets/unrelated data. Record source, timestamp and digest.
6. Run local analysis; label missing logs and unsupported claims UNKNOWN.
7. Human-review evidence and report with `ACCEPTANCE_CHECKLIST.md`.
8. Approve the exact report digest before using a customer-approved delivery channel.
9. Record payment status from actual records; never count an indicative quote as income.
10. Apply the agreed retention/deletion process and record completion.

The current MVP does not perform live GitHub retrieval, external report delivery, payment processing, or automated deletion.
