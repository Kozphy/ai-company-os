# PR-07: Research citation metadata

**Status:** implemented locally; no remote repository or pull request is available.

**Objective:** make supplied research source records deduplicated and structured while clearly preserving uncertainty.

**Files changed:** `company_os/agents.py`, `company_os/worker.py`, `tests/test_jobs_agents.py`, capability/acceptance/plan docs and local test evidence.

**Architecture:** offline research input accepts only HTTPS URLs without embedded credentials or localhost authority. It normalizes host casing, removes fragments, deduplicates canonical URLs, and parses ISO publication timestamps into explicit `PARSED_UNVERIFIED`, `UNKNOWN`, or `INVALID` states. All claims remain `UNVERIFIED`, content stays marked untrusted, and prompt-injection signals remain evidence only. No request is made to any URL.

**Migration impact:** none.

**Security impact:** this change performs no network retrieval and grants no tool authority. The URL restrictions reduce misleading citation forms but do not establish that a URL is public, safe to browse, or reliable.

**Automated tests and evidence:** Ruff passed; mypy reported no issues in 17 source files; `pytest -q tests` reported 32 passed with one Starlette/httpx deprecation warning. Regression covers canonical dedupe, URL rejection and parsed/invalid date states. See `../evidence/local-implementation-tests.md`.

**Known limitations:** retrieval, source reputation, publication-date verification, claim support and archive search remain unimplemented. HTTPS syntax is not source authorization or factual validation.

**Acceptance:** duplicate URLs collapse; credential-bearing and non-HTTPS URL forms are omitted; date uncertainty is explicit; no supplied claim is represented as verified.

**Rollback:** revert the URL/date helpers and associated evaluation/test changes. No stored schema changes or external effects.
