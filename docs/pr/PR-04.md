# PR-04: Engineering report policy gate

**Status:** implemented locally; no remote PR or GitHub mutation.

**Objective:** prevent read-only CFO analyzer recommendations from weakening required CI gates in generated reports.

**Files:** `company_os/agents.py`, `tests/test_jobs_agents.py`, `docs/ACCEPTANCE.md`, `docs/evidence/local-implementation-tests.md`.

**Architecture:** deterministic policy review runs on structured analyzer findings before Markdown rendering. Recommendations to quarantine, disable, delete, skip or make required checks non-blocking are replaced with an instruction to keep gates blocking, reproduce/fix the root cause, preserve coverage and obtain human review. This is a fixed safety rule, not an LLM judge.

**Migration impact:** none.

**Security impact:** no new authority or external effect. Upstream findings remain advisory; only a human may approve workflow changes.

**Automated tests:** `test_ci_policy_rewrites_recommendations_that_weaken_required_gates` and full `tests/test_jobs_agents.py`.

**Evidence:** Ruff passed, mypy reported no issues in 14 source files, and `pytest -vv tests` reported 26 passed in 2.85s with the audited CFO adapter active. One Starlette/httpx deprecation warning remains. Detailed commands are in `../evidence/local-implementation-tests.md`.

**Known limitations:** policy uses deterministic keyword matching and needs regression coverage if upstream recommendation text changes; it does not execute or edit workflows.

**Acceptance:** prohibited recommendation fixture is rewritten and marked `MANDATORY_GATES_PRESERVED`; the report carries a policy notice.

**Rollback:** revert the policy helper and its test. No schema or external state change.
